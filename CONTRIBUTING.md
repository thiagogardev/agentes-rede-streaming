# Como contribuir

Este repositório é um documento de arquitetura, não um sistema rodando. Contribuições bem-vindas:

- **Críticas e alternativas de arquitetura:** abra uma issue explicando o ponto, o risco que você vê e, se tiver, a referência (artigo, documentação, experiência em produção).
- **Erros e trechos confusos:** issue ou pull request direto no `docs/solucao-completa.md` ou nos READMEs.

*English: issues and pull requests in English are welcome too.*

Ao alterar o documento, mantenha o README em português e o [README.en.md](README.en.md) coerentes e registre a mudança no [CHANGELOG](CHANGELOG.md).

Ao contribuir, você concorda que sua contribuição seja distribuída sob a mesma licença do projeto (CC BY 4.0, veja [LICENSE](LICENSE)).
